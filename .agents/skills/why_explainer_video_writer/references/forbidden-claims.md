# 禁用表达与安全替换规范 (Forbidden Claims & Safe Replacements)

为确保知识型长视频的客观性、准确性与跨文化尊重，本文件列出文稿中**严禁直接使用的夸张、排外、绝对化、混淆起源及无证据表达**，并提供符合纪录片规范的**安全替换写法**。

> **基本准则**：除非某张高可靠度（`reliability: "high"`）的 `verified_fact` 证据卡明文记载了某项排他性记录，否则一律禁用绝对化词汇。

---

## 1. 绝对化范围与排他性表达（严禁无据使用）

| 禁用表达（高风险） | 风险原因 | 标准安全替换写法（纪录片规范） |
| :--- | :--- | :--- |
| “全世界只有中国 / 只有某国……” | 极易被反例推翻，全球往往存在相似地理或历史演化出的类似习俗 | “在世界主要国家和地区中，某国是把这一习惯普及得最彻底、最具代表性的地区之一……” |
| “所有外国人 / 所有西方人都不……” | 忽视不同国家、气候带、阶层与代际差异，以偏概全 | “在欧美许多国家和地区的日常饮食习惯中，普遍更倾向于……” |
| “自古以来所有人都……” | 古代不同朝代、地域、社会阶层的生活条件差异极大 | “从某时期留存的文献记载来看，当时具备条件的城镇居民中开始普遍出现……” |
| “没有任何一个民族能够……” | 缺乏全球人类学穷尽式证据，带有排他性独断色彩 | “受限于当时的自然环境与技术条件，很少有其他地区发展出同等规模的……” |
| “百分之百 / 绝无例外” | 社会与历史现象几乎不存在绝对无例外的规律 | “在绝大多数情况下 / 成为当时社会的主流选择” |

## 2. 单一归因与宿命论表达（严禁把复杂机制简单化）

| 禁用表达（高风险） | 风险原因 | 标准安全替换写法（纪录片规范） |
| :--- | :--- | :--- |
| “这唯一的原因就是……” | 历史与社会习惯几乎都是多因素（地理+经济+技术+制度）共同作用的结果 | “推动这一变化最核心的几个因素中，首先要看的是……” / “这背后的关键推手之一，是……” |
| “必然导致 / 注定会……” | 带有事后诸葛亮式的历史决定论色彩，忽视历史偶然性与制度选择 | “在当时的资源约束下，这顺理成章地促成了……” / “这一变化大大加速了……的形成” |
| “彻底决定了……的命运” | 过度夸张单一事件或器物的历史作用 | “这一转折对后来的生活习惯产生了深远影响” |

## 3. 极易混淆的四类“起源与发展”表述（必须严格区分）

在撰写历史、食物、技术或文化溯源时，**绝对禁止将以下四种截然不同的事实属性混为一谈**：

| 证据卡真实属性 | 禁用错误改写（偷换概念） | 准确规范写法 |
| :--- | :--- | :--- |
| **1. 某地最早出现**<br>(`earliest_occurrence`) | 写成“某地自古最为流行”或“某地最早实现商业化” | “根据目前的考古发现，这一器物/做法**最早出现于**某地的某遗址中，但早期仅限于小范围使用。” |
| **2. 某地最早有文字记录**<br>(`earliest_written_record`) | 写成“某地最早发明了……”或“人类历史上第一次出现……” | “就目前保存下来的历史文献而言，关于这一做法**最早的明确文字记载见于**某时期的某典籍。至于民间实际出现的时间，可能比文献记载更早。” |
| **3. 某地最早规模化生产**<br>(`earliest_mass_production`) | 写成“某地发明了这项技术” | “虽然这项技术的实验室原理早已出现，但**最早实现低成本、规模化工业生产**，并将其推向大众市场的，是某时期的某地区。” |
| **4. 某地最为流行 / 成为代表**<br>(`most_popular_or_widespread`) | 写成“这是某地独创的专利”或“起源于某地” | “这一做法并非某地独有，但经过近代基础设施与生活习惯的演变，它在某地**普及程度最高，最终成为了当地最具代表性的日常习惯**。” |

## 4. 传说、争议与推论的边界表达（严禁当成信史直叙）

| 证据卡 `claim_type` | 禁用写法（混淆事实边界） | 强制限定词与规范写法 |
| :--- | :--- | :--- |
| `legend_or_anecdote`<br>（民间传说或轶事） | “公元某年，某位皇帝在微服私访时意外打翻了罐子，从而发明了这道菜。”（把传说当真事写） | “关于这道菜的来历，**民间流传着许多故事，其中最广为人知的一种说法是**……不过，这类故事更多反映了后人的文化附会，并没有当时的史料直接佐证。” |
| `disputed_claim`<br>（学界或业界争议说法） | “历史学家已经证明，这一切都是因为……”（抹杀学界分歧） | “关于这一现象的具体成因，**目前研究者们还存在不同看法。一种观点认为……；而另一派学者则根据某资料指出……**” |
| `author_interpretation`<br>（资料作者推论/解读） | “事实就是，这种制度让人们养成了……”（把推论当客观统计） | “有研究者从社会学角度提出了一种解释：他们认为这种制度安排在客观上重塑了人们的日常习惯。” |

## 5. 排外、文化贬低与情绪煽动表达（零容忍禁区）

| 禁用表达类型 | 具体违规示例 | 标准安全替换写法 |
| :--- | :--- | :--- |
| **贬低他国/他地区生活习惯** | “西方人至今还保留着喝生冷水的原始/落后习惯”“某某地方的饮食简直荒谬” | “由于市政管网建设路径与制冷普及时间不同，欧美许多地区形成了以冷饮和直饮水为主的日常习惯。” |
| **伪科学体质优劣论** | “亚洲人的基因天生比外国人高贵/脆弱，所以只能……” | “除了生理耐受度的个体差异外，长期形成的饮食结构与公共卫生环境对饮水偏好的影响更为直接。” |
| **伪造历史人物心理与微表情** | “看着眼前的污水，市长冷笑了一声，内心充满了贪婪与轻蔑” | “当时的市政记录显示，议会起初因为改造成本高昂，推迟了供水管网翻新计划。” |
| **廉价煽情与宏大口号收尾** | “这就是我们老祖宗碾压全世界的顶级智慧！看完怎能不热泪盈眶！” | “当我们今天随手接起一杯温水时，背后其实连着几代人在公共卫生、能源利用和工业制造上走过的漫长道路。” |
