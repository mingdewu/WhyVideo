# 镜头视觉类型选型与参数规范 (Scene Type Rules)

`why_explainer_video_producer` 严格限定每个镜头的 `scene_type` 只能从以下 **6 种标准枚举** 中选择。任何不在此列表中的自定义类型均视为非法。

---

## 1. 六种允许的视觉类型一览

| `scene_type` 枚举值 | 中文名称 | 适用旁白场景 | 是否依赖外部实拍/图片素材 | 可否作为缺素材时的 `fallback` |
| :--- | :--- | :--- | :---: | :---: |
| **`broll_video`** | 实拍动态视频 | 现代日常生活细节、物理/化学实验过程、工业流水线运转、食物烹饪或器物操作微距实拍 | 是（需 `video` 素材） | ❌ 否 |
| **`photo_motion`** | 档案图片视差动效 | 历史老照片、发明专利图纸、古籍书影、历史人物肖像、馆藏文物静物图（配 Ken Burns 推拉摇移与局部高亮） | 是（需 `image` 素材） | ❌ 否 |
| **`map`** | 动态地理信息图 | 地理位置分布、气候带划分、历史疆域/政区参照、原料产区、贸易路线或跨地区传播路径 | 否（程序化组件） | ✅ 是 |
| **`timeline`** | 演进时间轴 | 历史年代递进、技术迭代里程碑、多项事件先后顺序对比、朝代/时期跨越 | 否（程序化组件） | ✅ 是 |
| **`data_card`** | 数据与机制卡片 | 成本账本算账对比、物理/工程原理拆解图、统计比例、多维优劣势对照表 | 否（程序化组件） | ✅ 是 |
| **`kinetic_text`** | 动态排版文字 | 开篇核心提问抛出、关键概念定义、破除常见迷思（Myth vs. Reality）、全片唯一结尾核心结论收束 | 否（程序化组件） | ✅ 是 |

---

## 2. 各类型详细设计规范

### 2.1 `broll_video`（实拍动态视频）
- **核心要求**：画面主体清晰、无第三方水印、无杂乱字幕、无显著商业 Logo 特写。
- **运镜与裁切**：支持 `full_frame_slow_push`（全画幅微推）、`split_screen_comparison`（分屏对比）等模式。
- **缺素材降级**：若 `asset-index.json` 中没有高度匹配且 `license_status === "approved"` 的视频素材，严禁随便拿风景或办公室空镜凑数，必须标记 `NEEDS_HUMAN_ASSET` 并配置 `data_card` 或 `kinetic_text` 作为 `fallback`。

### 2.2 `photo_motion`（档案图片视差动效）
- **核心要求**：禁止将静态图片直接死板贴在画面上不动。必须指定明确的 `crop_mode`（如 `ken_burns_zoom_in`、`pan_top_to_bottom`、`spotlight_callout_box`）。
- **历史真实性**：用于历史场景时，图片的拍摄/绘制年代必须与旁白所讲时期一致（严禁拿清末照片配宋代旁白），且必须触发 `human_review_required: true`。

### 2.3 `map`（动态地理信息图）
- **核心要求**：明确指定地图中心坐标/区域、高亮图层、路径箭头方向与地名标签。
- **强制审核**：所有 `scene_type === "map"` 的镜头一律强制 `human_review_required: true`，由人工核对地图边界、历史地名与空间方位的准确性。

### 2.4 `timeline`（演进时间轴）
- **核心要求**：单屏时间轴节点控制在 **2–4 个** 以内，突出当前旁白所在的年份节点（高亮显示年份、事件短标题与因果箭头）。

### 2.5 `data_card`（数据与机制卡片）
- **核心要求**：最适合解决“为什么”视频中的**算账逻辑**与**物理/工程机制对比**（例如“直面条 vs. 波浪面条”在蒸熟度、脱水速度、抗压强度三个维度的对比卡片）。
- **信息密度控制**：单张卡片不超过 3 个对比维度，每个维度文字不超过 12 个汉字，配合直观图标或矢量结构示意。

### 2.6 `kinetic_text`（动态排版文字）
- **核心要求**：提炼旁白中的核心主干问题或核心反转结论（字数控制在 10–24 字以内），利用字重对比、色彩高亮与入场节奏强化记忆点。
- **禁止滥用**：不要把整段 60 字的旁白原封不动塞进 `kinetic_text`，那是字幕（Captions）的工作，不是动态排版画面。
