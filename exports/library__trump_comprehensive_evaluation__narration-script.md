# 全方位评价美国总统特朗普

> 从 AntiGravity 聊天记录整理。开篇与前三章采用聊天中幽默口语化重写版，后续章节采用各章最终旁白；最后一章回复含全片正式结尾。

### 全新开篇导言：为什么大家都爱聊他，但又经常聊歪？

聊起特朗普，大家脑海里跳出来的画面大概都差不多：金黄色的标志性发型、两根手指在胸前有节奏地比划、深夜在推特上火力全开，或者在白宫椭圆形办公室里大口嚼着麦当劳汉堡。

喜欢他的人，觉得他简直是个降维打击的英雄：说话接地气，敢当面怼专家，专治各种虚伪的建制派政客；
讨厌他的人，觉得他像个闯进精美瓷器店的野牛，把二战以来几代人辛苦搭好的规矩踩了个稀巴烂。

但如果我们聊特朗普，整天只盯着他又发了什么离谱推特、说了什么得罪人的雷人雷语，那咱们就太小看现代政治的深水区了。

说白了，特朗普能一路杀进白宫，绝不是靠嘴碎或者运气好，更不是哪天早上外星人突然降临了。他的出现，其实是美国过去几十年累积的一场“高烧”。

在这个亿万富翁的背后，藏着几千万被时代甩下车的普通老百姓的真实绝望，也藏着一套把美国税收、法院、外贸规矩甚至整个世界秩序都掀翻重组的庞大机器。

今天这期视频，咱们就抛开那些假大空的政客套话，用人话把这张账本从里到外扒个底朝天：看看这个曼哈顿商人，到底是怎样凭一己之力，把全世界最有权力的国家，带进了一场谁都回不去的超级大实验。

要弄懂这一切，咱们得先坐上一辆长途大巴，去美国的铁锈带小镇转一圈。

### 第 1 章：铁锈带的反叛——为什么炼钢师傅会爱上地产大亨？

#### 一、一场把专家打蒙的政治反差

2016年那个大选夜，全美国的政客和专家，基本上经历了集体脑干宕机。

按照过去三十年的传统剧本，美国的五大湖周围——像宾夕法尼亚、密歇根、威斯康星这些地方，那是民主党雷打不动的“铁饭碗”，大家管它叫“蓝墙”。为什么？因为这里全是炼钢的、造汽车的、开叉车的产业工人，祖孙三代都是铁杆工会成员。

而他们的对手是谁？唐纳德·特朗普。一个在纽约第五大道顶层镀金豪宅里出生长大的地产大佬，平时最大的爱好就是在真人秀电视里指着别人的鼻子吼：“你被开除了！”

按理说，这两个群体八竿子打不着。一个每天满手油污在车间挥汗如雨，一个出入坐私人飞机吃顶级牛排。但神奇的事情就在这里发生了：这群在厂房里干了一辈子的硬汉，竟然集体把票投给了这个连扳手都没摸过的纽约阔少。

为什么？难道几百万工人突然集体审美疲劳了吗？

#### 二、专家算的是算盘，工人丢的是饭碗

要解开这个谜，得先看看过去的几十年里，华盛顿那些名校毕业的精英专家们，到底给老百姓画了一张什么样的大饼。

上世纪八九十年代开始，全球化大潮来了。专家们拍着胸脯跟老百姓讲：这是天大的好事啊！你看，高大上的金融、科技、软件留在咱们美国；那些又脏又累的炼钢、纺织、组装，统统转移到海外去。这样不仅外国发展了，咱们美国老百姓还能买到超级便宜的衣服和电视机，这不是双赢吗？

算盘打得噼里啪啦响，账本看着确实很漂亮。但专家们唯独忘了一件事：那个在小镇钢厂干了半辈子、今年四十五岁的炉前工，他丢了工作之后，到底该怎么活？

根据美国劳工统计局的冷冰冰的数据，从2000年到2010年，短短十年时间，美国整整蒸发掉了560万个制造业岗位。

在许多内陆小城，一家几千人的老钢厂关停，绝不仅仅是几千人下岗那么简单。厂子没了，镇上的税收当场断崖式暴跌；跟着倒霉的是修路的钱没了，公立学校开始裁老师，街边的披萨店、修车铺接二连三倒闭，整个小镇在几年之内迅速变成死气沉沉的鬼城，随之而来的就是失业酗酒和阿片类止痛药泛滥。

更让工人们血压拉满的是精英政客的反应。

两党政客竞选时都说“工人阶级是国家脊梁”，一选上转头就去达沃斯论坛举杯香槟。对于那些失去工作的四五十岁工人，精英们给出的终极建议竟然是：“大家别灰心，可以去社区大学重新学写代码嘛！”

这就好比你家房子着火了，消防员走过来递给你一本高等数学，让你自学成才去当程序员一样荒诞。

#### 三、八万张“掀桌子”的选票

工人们胸口憋了几十年的这口恶气，在2016年，终于等来了一个懂怎么“点火”的人。

特朗普跟那些满嘴外交辞令、生怕得罪任何人的传统政客完全不一样。他直接摘掉领带，扣上一顶十来块钱的红色卡车司机帽，站在破旧的厂房前面，拿着大喇叭用大白话喊：

“根本不是你们不够努力！是华盛顿那帮满嘴跑火车的政客把你们给出卖了！他们为了自己的利益，把你们的工厂白白送给了别人！”

不管这些话在经济学上有多少争议，但对于这群被冷落了几十年的工人来说，这是几十年里头一次有总统候选人看着他们的眼睛，承认他们的委屈和愤怒。

皮尤研究中心选后的统计数据写得明明白白：在没有大学学历的白人蓝领选民里，特朗普拿到了整整64%的选票，把对手远远甩在身后。而在决定胜负的密歇根、威斯康星和宾夕法尼亚这三个关键州，特朗普加起来赢了多少？不到八万票。

这不到八万张票，就像几百万工人联合起来朝华盛顿的精英桌面上扔了一颗臭鸡蛋：既然你们这套所谓的体面游戏从来不带我们玩，那我们就选一个能把你们桌子彻底掀翻的人！

工人们用选票完成了一场载入史册的反叛。但问题是，豪言壮语喊完了，狂欢的集会散场了，当这个商人总统真正坐在白宫办公桌前，他开出的药方，真的能把失去的工厂给变回来吗？

### 第 2 章：减税与关税——白宫账房里的神奇过山车

#### 一、左手松油门，右手踩刹车

特朗普刚进白宫那会儿，大家都在猜他会怎么拯救美国经济。结果这位老哥一出手，直接把所有经济学教授给整不会了。

因为他几乎在同一时间，干了两件在教科书里完全打架的事。

第一件事，是给全美的大公司发史诗级大红包——疯狂减税，告诉大家：尽情赚钱，政策给你们松绑！
第二件事，是突然从裤兜里掏出高额关税大棒，往全世界头上一顿乱挥，告诉大家：外面的东西想进来？门都没有，先交过路费！

在经典的经济学课本里，减税是自由市场的玩法，鼓励资本全球到处跑；关税是闭关锁国的玩法，逼着资本必须留在国内。特朗普不管这一套，他把两脚油门一起踩到底，非要把这两味药炖在一锅汤里喝。

这场二战以来最奇葩的宏观经济大冒险，就这么轰轰烈烈地开张了。

#### 二、公司税降了，钱到底去哪儿了？

咱们先来看第一个大招：减税。

2017年底，特朗普签下了著名的《减税与就业法案》。这里面最核心的一招，是把美国公司的联邦所得税率，直接从高高在上的35%，咔嚓一刀切到了21%。而且这一条是永久生效。

白宫当时的宣传话术很动人：大家想想看，公司税负少了一大半，省下来的万亿美元，老板们不得赶紧在铁锈带买地盖楼、买新机器、招更多的工人和加薪吗？

在头两年里，这招确实把气氛烘托到了顶点。公司账面利润飙升，华尔街股市天天放烟花创历史新高，失业率一路跌到半个世纪以来的最低点3.5%，特朗普天天发推特为自己点赞。

但当美国国会预算办公室（CBO）坐下来认真翻看账本时，脸上的表情就没那么轻松了。

首先，国会预算办公室一算账：这项法案十年里直接给联邦财政捅了一个大概1.5万亿美元的大窟窿。国库里的赤字蹭蹭往上窜。

更尴尬的是，那些拿到大笔税收减免的跨国巨头们，压根没有像白宫幻想的那样，屁颠屁颠跑回铁锈带修新厂房。老板们的心思精明得很：他们把省下来的大笔现金，大部分用来在股市上疯狂回购自家股票、给高管发年终奖和给大股东分红。

这等于说，国家背了一屁股债给企业发补贴，结果华尔街的富豪们账户余额翻了倍，而铁锈带原本空荡荡的厂房里，依然只有北风在呼呼地吹。

#### 三、满世界贴罚单，结果自家农场主先躺枪

如果说减税还算是传统共和党的老把戏，那么加征关税，就纯粹是特朗普个人的“独家绝活”了。

从2018年开始，特朗普彻底把世界贸易组织当成了空气。他翻出冷战时期的陈旧法案，以“国家安全”当借口，今天对进口钢铁铝材加25%关税，明天给几千种消费品贴上高额关税标签。

特朗普在镜头前讲得特别带劲，他说：“关税就是外国人在给美国财政部送钱，我们赚麻了！”

但只要稍微买过菜的人都知道，关税这玩意儿哪有那么简单？外国生产商可不会自掏腰包给你补贴，关税是美国进口商在海关拿真金白银垫付的。这笔成本层层往下传导，最终全落在了谁头上？全落在了美国本土老百姓和制造业下游企业的头上。

那些造推土机、修大楼的美国公司突然发现，本来指望买点便宜钢材省钱，结果关税一砸下来，原材料价格暴涨，自己的利润当场腰斩。

紧接着，更打脸的反转来了：被加了关税的国家可不是吃素的，反手就挑美国最要命的地方打——直接宣布大幅减少采购美国中西部的大豆、猪肉和谷物。

这下子可把美国的农场主们整崩溃了。农场里的大豆堆积如山运不出去，眼看这帮最铁杆的选民就要在下次选举中造反。

特朗普一看情况不妙，怎么办？只能赶紧让美国财政部开闸放水。在2018年到2020年之间，联邦政府通过农业补贴计划，给受损失的美国农户累计直接发了大约280亿美元的现金救济款。

大家看明白这个黑色幽默的资金闭环了吗？
政府用关税从进口商和消费者手里收了钱，转手又掏出国库里差不多的巨款，全额补贴给卖不掉粮食的自家农民。折腾了一大圈，谁都没真正发财，除了海关的公务员忙得脚打后脑勺。

根据劳工统计局的数据，在疫情发生之前的2017到2019年，美国制造业确实多了大约45万个工作岗位。但这个增长，大部分只是战后经济长周期的自然喘息。制造业在整个美国经济里的占比，依然死死焊在11%左右，一动没动。

全球化分工几十年形成的产业链底座，哪是发几条推特、加几轮关税就能瞬间翻盘的？

#### 四、真正的大招在法院里

看完经济这一盘账，很多人可能会得出结论：这不就是雷声大雨点小吗？折腾来折腾去，债务多了，成本高了，好像也没真正把五大湖变成世界工业中心啊。

如果特朗普的能耐仅限于此，那他可能也就是个风风火火的过客。

但所有人都忽略了一件事：税收政策和关税是可以随时被下一任总统改回去的。但特朗普在位四年，却在暗地里悄悄给美国打进了一枚谁也拔不掉的钢钉。

这枚钢钉，不仅将决定全美未来几十年的规矩走向，甚至连平时最瞧不起他这身痞气的保守派精英，在看到这一战果时，都不得不心服口服地给他立碑立传。

这个没有硝烟但杀伤力惊人的战场，就是美国的联邦最高法院。

### 第 3 章：半个世纪的终局——他是怎么把法院变成自己人的？

#### 一、白宫里最反常的联盟

在华盛顿的政客圈子里，特朗普对司法系统的态度，可以说让所有法官老爷们血压飙升。

别的大统领面对法院判决，哪怕心里骂娘，表面上也得维持尊重：“我们虽然不同意，但服从法律程序。”
特朗普完全不吃这套。心情不爽了，直接在推特上开麦，说判他输的法官是“政治打手”，甚至直接把法官分门别类，叫他们“奥巴马法官”或者“克林顿法官”，气得最高法院首席大法官罗伯茨亲自发文喊话，说美国压根没有这种党派法官的说法。

但是，魔幻的事情又来了。

如果你跑去问那些全美最顶级的保守派法律专家，或者去南方问那些每周日都去做礼拜的几千万虔诚选民：“你们觉得特朗普干得怎么样？”

他们很可能会压低声音，但眼睛放光地告诉你：
“虽然这人私生活乱七八糟、嘴巴没把门、发推特像个小混混，但他，是我们这五十年来最伟大的救星！”

这听起来简直不可思议，对吧？一个满嘴跑火车的大亨，怎么就成了这帮老学究和信徒心里的救世主了？

#### 二、终身制的魔力与一份秘密清单

答案很简单：因为特朗普给了他们这帮人做梦都想拿、但整整两代建制派政客都没能弄到手的东西——最高法院的绝对掌控权。

美国的体制很有意思。总统能签的行政令，换个总统进白宫，拿支笔一划就作废了；国会费尽九牛二虎之力通过的法律，几年后席位一变，也能重新推翻。

但唯独有一种官，权力大得惊人，而且一旦坐上去就谁也赶不走——那就是联邦各级法院的法官。只要他们自己不辞职、没犯大罪被弹劾，他们就能一直干到生命最后一刻。

这意味着什么？意味着一个四五十岁年富力强的法官只要坐进法院，他就能用自己脑子里的思想，把全美老百姓的规矩直接管上三十年、四十年，甚至跨越整整两代人！

早在2016年参选的时候，老江湖特朗普就看透了这群保守派精英的心思。

当时这帮人根本信不过特朗普，觉得他以前又支持过民主党、又结过三次婚，思想根本不纯洁。特朗普二话不说，直接甩出一张硬核底牌。他对保守派大佬们说：

“咱们打开天窗说亮话。我懂做生意，你们懂法律。只要你们在大选里死心塌地挺我，我向你们发誓：我当上总统后的所有最高法院法官提名，一个都不我自己瞎琢磨，全由你们保守派最权威的‘联邦党人学会’挑人，名单你们定，我只负责在上面盖章！”

这一下，双方一拍即合。一场各取所需的“世纪大联姻”，正式结盟了。

#### 三、四年三连击与神级运气

当特朗普入主白宫后，参议院共和党领袖麦康奈尔立马把这件事干成了最高级别的政治攻坚战。他们把议事规则全改了，把阻碍提名的门槛直接踩碎，白宫和参议院开启了一台疯狂运转的法官盖章流水线。

在短短四年任期里，特朗普一共任命了234位终身制联邦法官。全美十三个巡回上诉法院里，有三个法院的保守派力量直接从少数变成了多数。

但更夸张的，是特朗普那好到令人发指的“政治运气”。

在正常情况下，一位总统干满四年，能赶上一位最高法院大法官退休就算不错了。结果特朗普四年里，像开挂一样，一口气砸进了三张王牌：

第一张牌，是2017年上任没多久，接替去世的保守派旗帜斯卡利亚。这位置本来是前任奥巴马的，但参议院硬生生拖了将近一年不给奥巴马开会，硬是把这个席位熬到了特朗普手里，换上了四十多岁少壮派的戈萨奇；

第二张牌，是2018年关键摇摆法官肯尼迪退休，特朗普顶着全国范围的激烈争议，强行把卡瓦诺大法官硬顶了上去；

如果说前两张牌已经够猛了，那么第三张牌简直是老天爷递过来的“剧本杀”。在2020年大选投票只剩几周的时候，自由派的超级精神偶像金斯伯格大法官因病去世。共和党参议院以百米冲刺的速度，在选前几天闪电通过了年仅48岁的保守派女法官巴雷特的任命。

四年三连击！

最高法院九人裁判席上，保守派和自由派的比例，直接被生生打成了6比3的绝对压倒性优势。

法院判决对他不利？那叫“腐败的体制在暗算我们”；
主流媒体报道他的丑闻？那叫“既得利益集团在恐慌”。

要想看懂这个魔幻现象，你得明白：特朗普在白宫四年，干了一件极其狠辣的事情——他把美国两党的政治底层代码给彻底改写了。

咱们先看共和党。在特朗普出现之前，传统的共和党那是典型的“富豪与大企业俱乐部”。他们奉行里根时代以来的教条：政府别管事、税率越低越好、支持自由贸易，跨国大老板们爱去哪儿建厂就去哪儿建厂。

而特朗普硬生生凭借自己的号召力，把这个百年老党变成了一个高举“民粹主义”、靠铁锈带蓝领工人和中下层农民撑腰的劳工政党。现在任何一个共和党议员，只要敢在国会里公开宣称“我们要搞零关税自由贸易、把工厂搬去国外”，第二天他的选票就会被愤怒的自家选民撕成碎片。

再看对面的民主党，这就更有意思了。

民主党以前自称是劳动人民的贴心人，结果在2016年被特朗普在铁锈带偷了家，打得措手不及。现在民主党如果想赢大选，他就必须死守五大湖那几个关键摇摆州。

这就意味着，哪怕民主党明知道高额关税可能会推高物价、带来各种通胀后遗症，他也绝对不敢把关税取消。因为在政治选举的冷酷算盘里，物价高了可以赖给全球供应链，但要是谁敢取消关税，对面的对手就会立刻扣上一顶大帽子：“看到没有？这家伙要砸咱们铁锈带工人的饭碗！”

就这样，特朗普用四年时间，生生把全美两党的意识形态基准线，往贸易保护和孤立主义的方向狠狠拽过去了十万八千里。

#### 三、旧神庙倒塌，没人再提自由市场

现在的华盛顿政坛，呈现出一种前所未有的奇特景观。

三十年前冷战刚结束那会儿，两党政客们在电视上张口闭口都是“历史终结了”、“全球化是不可阻挡的历史潮流”。谁要是敢质疑自由贸易，谁就会被全美主流媒体当成不懂经济学常识的乡巴佬。

而今天呢？“供应链安全”、“产业自立自强”、“友岸外包”，成了华盛顿每一场政策研讨会的必讲词汇。那个曾经由美国亲手搭建、主导了半个多世纪的全球自由贸易神话，在不知不觉中，已经被所有人默默扔进了历史的故纸堆。

很多历史学者和观察家在复盘这段历史时都不得不承认：你可以极其厌恶特朗普这个人的性格、品行甚至他的行事风格，但你绝对无法否认，他是二战之后极少数能够以一己之力，把整个超级大国的国家运行航向，彻底扭转到一个全新方向的总统。

他虽然离开了那个房间，但他立下的规矩，却成了所有人不得不遵循的游戏规则。

### 全片唯一收束大结局 (Single Final Ending)

#### 那个撕开温和假面的人

看到这里，我们终于可以回过头来，直面开篇提出的那个终极问题：我们究竟该如何全方位评价唐纳德·特朗普？

如果你试图用一张简单的满分或者零分的打分表去给这个人定性，那你注定会陷入无休止的党派争吵里。

特朗普绝对不是一个完美无瑕的救世主。他在执政期间对宪政惯例的肆意践踏、在社交媒体上制造的无休止的人身攻击、在大选争议中对民主制度运转造成的巨大压力，以及大规模减税所带来的沉重财政赤字，都是客观存在、无法洗白的真实历史账本。

但与此同时，把美国今天所有的撕裂、对立和混乱，统统归咎于他一个人，同样是极其浅薄的推卸责任。

特朗普从来都不是制造美国深层伤口的“病因”，他其实是一个早已深病的庞大帝国，在世纪之交所猛烈爆发出来的“体征”。

在他出现之前，冰面下的裂缝早已蔓延了几十年：铁锈带凋零的烟囱、贫富之间不可逾越的鸿沟、两党精英在象牙塔里的傲慢自满，以及被全球化红利彻底遗忘的数千万普通工薪家庭。那些问题早已在那里腐烂发臭，只是传统的华盛顿政客习惯了用体面的外交辞令、精致的政治礼仪，把这块遮羞布严严实实地盖上，假装岁月静好。

而特朗普就像一个横冲直撞的野蛮施工员，用最粗暴、最刺耳、甚至最不体面的方式，当着全世界的面，把那块遮羞布一把扯了下来，露出了下面触目惊心的疮疤。

他留给美国的，不是几篇华丽的演讲或者几场热闹的集会，而是一个被彻底重组了保守派天平的最高法院、一套被完全重构的全球贸易游戏规则，以及两党再也回不去的政治底层逻辑。

历史最终记下唐纳德·特朗普的方式，或许永远不会是一个温和慈祥的治世元首；
但历史一定会清清楚楚地写下一笔：在21世纪的头二十年里，正是这个来自曼哈顿的地产商人，以近乎掀桌子的姿态，彻底砸碎了战后美国的旧剧本，把这个超级大国，推向了一场不可逆转的历史拐点。
