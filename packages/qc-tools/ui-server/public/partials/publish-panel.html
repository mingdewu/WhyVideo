YouTube 连接设置

长期自动续期（推荐 · Google OAuth）

授权一次长期有效

1. 在 Google Cloud Console 启用 YouTube Data API v3，创建 Web 应用 类型的 OAuth 2.0 客户端 ID。

2. 将下方回调地址填入「已获授权的重定向 URI」（若应用处于“测试”状态，令牌会在 7 天后过期；在 Google Cloud 将发布状态改为“生产”可避免 7 天过期）。

3. 填入 Client ID 与 Client Secret 并完成一次授权，后端会安全保存 Refresh Token 并自动续期。

弹窗被拦截？点此手动打开 Google 授权页面 ↗

备用：手动粘贴临时 Access Token（仅 1 小时有效）

上传视频、封面和字幕需要 youtube.force-ssl 权限；此方式保存在当前浏览器本地存储中，约 1 小时后需要重新粘贴。
